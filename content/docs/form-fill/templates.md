A Form Fill template is a saved **target form** — the PDF or DOCX you fill into — so you can reuse it across runs without uploading it every time. Any form options you set are saved with it too.

> **Note:** Form Fill templates are different from [Universal Document Analysis templates](/docs/universal-document-analysis/templates). UDA templates store the *fields to extract*; Form Fill templates store the *form to fill*.

## Save a target as a template

You create a template while setting up a run, from the **Target** section:

1. Keep **Upload target** selected and upload your PDF or DOCX form.
2. Tick **Save this target as a reusable Form Fill template**.
3. Enter a **Template name** (required) and an optional **Template description**.
4. Set any form options — *Fill entries in chronological order*, and *Allow AI to add new rows or columns* for DOCX forms. These are saved with the template.
5. Click **Run Form Fill**. The target is saved as a template at the same time the run starts.

> **Tip:** Saving a target as a template doesn't change how the current run works — it just keeps a copy of the form (and its options) for next time.

## Use a template

1. In the **Target** section, switch to **Saved template**.
2. Open the **Saved target template** dropdown and choose your form. Each entry shows its name and format, for example *Engagement Letter (DOCX)*.
3. The template's original filename, description, and saved options load automatically. Adjust the options for this run if you like — your changes apply to this run without altering the saved template.

If you haven't saved any templates yet, the dropdown shows a reminder to upload a target and save it as a template first.
