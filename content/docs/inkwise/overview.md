Inkwise is an AI writing workspace built around your own sources. Add reference material to a library, bind the references you need to a document, and write with an AI that drafts, rewrites, and answers questions — citing the sources behind every grounded suggestion. The result is a finished document with citations you can trace back to the evidence.

## What you can do

- **Write in a rich editor with AI help** — get inline predictions as you type, and rewrite selected text with one-click tools (Coherent, Concise, Detailed, Humanize, or a custom instruction).
- **Build a reusable reference library** — upload documents, images, audio, video, ZIPs, captured webpages, or Google Drive files once, then use them across any document.
- **Chat with your sources** — ask grounded questions in a side panel and insert the answers straight into your draft.
- **Cite as you write** — grounded predictions, rewrites, and chat answers carry citations formatted in the style you choose (APA, MLA, Chicago, Bluebook, and more).

## How the pieces fit together

Inkwise has three sections, switched from the menu bar at the top of every Inkwise page:

| Section | What it does |
| --- | --- |
| **Write** | Your documents and the editor where you write, get AI help, chat, and review changes. |
| **References** | Your source library — everything you upload or import, processed so it can ground the AI. |
| **Templates** | Reusable starting points for new documents, both your own and built-in system templates. |

The link between them is *binding*: you add material in **References**, then bind the sources you need to a document in **Write**. Only bound, processed sources can ground the AI's predictions, rewrites, and chat answers.

## Where to find it

Inkwise is in the left sidebar of the dashboard under **Inkwise** (`/dashboard/inkwise`). Inside Inkwise, the menu bar switches between the three sections:

- **Write** — documents and the editor (`/dashboard/inkwise/write`)
- **References** — your source library (`/dashboard/inkwise/references`)
- **Templates** — document starting points (`/dashboard/inkwise/templates`)

## Supported reference files and limits

You can add these kinds of references:

| Type | Notes |
| --- | --- |
| PDF | Processed directly. |
| DOCX (Word) | Converted to PDF during processing. |
| Images (JPG, PNG) | Read for grounding. |
| ZIP | Automatically unpacked; only supported file types inside are kept. |
| Webpage | Captured from a URL you provide. |
| Google Drive files | Imported from files you select. |
| Audio (MP3, WAV) and video (MP4, MPEG) | **Pro plan only.** |

> **Note:** Documents can be up to **100 MB** each (video up to **1000 MB**). You can bind up to **100 sources** to a single document. Audio and video references require the **Pro plan**.

## Write your first document in four steps

1. Open **References** and add a few sources. Wait until each shows **Ready for binding**.
2. Open **Write**, click **New document**, and give it a title.
3. In the editor's right sidebar, open the **References** tab and **Bind** the sources you want to use.
4. Start writing — accept inline predictions with **Tab**, rewrite text with the writing tools, or ask the **AI Chat** about your sources.

For the full walkthrough of the editor and workspace, continue to [Writing Documents](/docs/inkwise/writing-documents).
