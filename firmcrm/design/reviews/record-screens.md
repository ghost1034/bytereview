# Design QA — Record pages, Admin, Data, Settings

Reviewed against `design/proposals/finance/DESIGN.md` (Direction B, "Finance-grade editorial").
App build: Vite dev on :5186, admin@demo.firm, 2026-08-22. Viewports: 1440×900 (target), 1280×900, 1180×900.
Method: live inspection with computed-style probes (private headless Chrome via CDP, plus the shared chrome-devtools session) and source cross-check of `frontend/src/pages/*`, `components/ui/*`, `components/crm/*`, `components/layout/Shell.tsx`.

Screens covered: Login (+ session-expired notice, wrong-password), Leads (list, New, Edit, Convert with duplicate warning, empty filter), Accounts (list, Show archived, Export, New incl. duplicate name), Account detail `/accounts/11` and `/accounts/3` (all 6 tabs, Edit, Add contact, Archive/Restore, Raise/Lift wall), Contacts list + detail, Engagements (+ edit), Campaigns (list, side panel, member add/status/remove), My Tasks (3 tabs), Data, Admin (5 tabs, Add/Edit user), Settings (+ invalid submit), forced password change (new user), toasts (success + error), skeletons, 1280/1180, keyboard navigation of the New lead form, contrast.

Severity: **P0** blocks credibility · **P1** clearly off-spec · **P2** polish.

## Verified OK (no action)

- Tokens: no slate/emerald/teal/sky/violet in computed styles; canvas #F7F5F1, surfaces white, hairlines sand-150/100, accent #4B55C8; shadows only on modal/menu/toast (spec values confirmed).
- Typography: Geist, 13/20 body, `tnum` global; page titles 20/28/600 −0.015em; labels and table headers 12/500 normal case (no uppercase/tracking anywhere); counts on tabs in 11px mono.
- Tables: header 36px sand-25 with sand-150 rule, sticky; rows 40px; money right-aligned tabular 500; counts 400; dashes in sand-300 for empty; sortable headers with chevron; hover tint; pagination footer 44px "1–50 of 52" with page-size select and ghost Prev/Next; skeleton loading (12px bars, 1.4s pulse, `aria-busy`), no spinners.
- Badges: dot+label in tables; filled pills only in headers (Prospect/Client/Archived/Restricted); tones correct for client/prospect/adverse/high/medium/low/active/completed/planned.
- Buttons: 28/32/36 sizes, one primary per page header, danger variant for Lift wall / Sign out everywhere, ghost for Archive/Prev/Next.
- Modal: 512/672px, 12px radius, hairline border, `shadow-modal`, scrim rgba(26,25,22,.32), header 16/20, body 20, footer sand-25; Escape closes; fade 160ms.
- Toast: 360px, sand-900, 12px radius, `shadow-toast`, success 4s / error 8s; success and error both exercised ("Account archived", "Account has open opportunities; close or archive them first").
- Tabs: 36px, 20px gap, sand-900 underline; facts grid 6 cells with hairline dividers; activity timeline matches §6.14 (24px discs, day headers, 12px tabular stamps, actor in 500); Raise-wall/Restricted states and duplicate-account inline warning use the warn/danger semantics correctly.
- Copy: no exclamation marks or emoji found in any reviewed screen.

## Verdict

1. The token and typography migration is complete and faithful: warm neutrals, indigo accent, tabular numerals, normal-case labels, 40px tables, skeletons and overlay-only shadows all match the spec on every record screen.
2. Two patterns undermine credibility everywhere: native `confirm()`/`prompt()` dialogs for all destructive actions, and modals without focus management (keyboard users tab into the page behind the scrim).
3. Density is slightly over-tightened: two-line record cells in 40px rows, name columns squeezed by fixed secondary widths, and facts values truncating at the 1440 target.
4. The 1180–1439 range is not yet supported as the spec claims: list tables overflow horizontally (Leads hides its Convert action) and the facts grid clips money.
5. Fix P0 #1–#2 and P1 #4–#8 (focus trap, confirm dialog, inline validation, 52px two-line rows, column widths, facts wrapping) and the record screens are ready for the core/board reviews to build on.
